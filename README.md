# Telemetry 

## Sensor 

- Code in the [sensor](./sensor/) directory is meant for ESPs connected to watermark sensors 

## Gateway 

- Code in the [gateway](./gateway/) directory is meant for ESPs with SIM7606 modules for receiving data from sensors and forwarding packets to remote server 

## Library 

- Code in the [lib](./lib) directory is meant to be shared between the two
